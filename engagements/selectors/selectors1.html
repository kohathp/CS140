CSS Selectors

You can select an item by its tag, class, or ID. You can also select items using descendant and child selectors. You can select all items with the universal selector. You can select items by attributes, pseudo‑classes, and pseudo‑elements.

An ID is used for one unique element. A class is used for multiple elements. IDs use # and classes use .

A SPAN is an inline element. A DIV is a block‑level element. SPAN is for small text pieces, and DIV is for larger sections.

A DIV is a generic block with no meaning. HEADER, MAIN, and FOOTER are semantic tags with specific meaning. They describe the structure of the page.

You can select a color using named colors or by using a drop down table or using hex codes.
